## Projects

### **CSV-ORM (C++ CSV ORM Library)**
A lightweight ORM-style C++ library for treating CSV files as structured tables.  
Implements strict typing, RAII-safe mutations, query pipelines, and complete file rewrite with rollback guarantees.  

You can visit it [here](https://github.com/andresaugom/CSV-ORM).
